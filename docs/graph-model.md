# Графовая модель Corporate Data Platform

## Назначение

Графовый аналитический модуль исследует структурные связи между объектами корпоративной системы.

## Используемые инструменты

- NetworkX — создание графа и расчет характеристик.
- DuckDB — чтение исходных данных из CSV.
- Matplotlib — построение и сохранение визуализации.

## Источник данных

`data/raw/companies.csv`.

## Типы вершин

- `company` — организация; атрибуты включают название и число сотрудников.
- `city` — город.
- `industry` — отрасль.

Идентификаторы имеют префиксы `company:`, `city:` и `industry:`, чтобы разные типы
объектов с одинаковым названием не объединялись в одну вершину.

## Типы отношений

- `located_in` — организация расположена в городе.
- `operates_in` — организация относится к отрасли.

Граф неориентированный: ребро представляет соответствие объектов и не задает направление.

## Основные операции

- Создание вершин и ребер на основе CSV.
- Поиск соседних вершин, организаций по городам и отраслям.
- Поиск общих связей между парами организаций.
- Расчет степеней и центральности по степени и посреднической центральности.
- Поиск компонент связности и кратчайших путей.
- Визуализация с помощью spring_layout.

## Результаты

- `analytics/reports/company_graph.png` — изображение графа, создается запуском визуализатора.
- `analytics/reports/graph_analysis.md` — интерпретация результатов.
